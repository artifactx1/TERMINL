# Arcade V1

`/os` is a focused launcher. Wen Lambo and Rekt Rumble lead; Moon Mission is the solo adventure below them. No desktop sidebar, Pixel Shop, credits, daily rewards, trophies, receipt exports, or ghost-challenge flow. The retired OS UI and receipt exporter have been removed. Legacy simulation/replay utilities remain for old data and regression coverage. Rug or Bond remains a standalone prototype at its existing URL and is not promoted in the V1 arcade.

## Longer sessions

- **Wen Lambo:** the six-course cup is the primary solo action. Quick Race and Learn to Drive remain available. Steering and online racing rules are unchanged by this refactor.
- **Rekt Rumble:** a six-fight solo circuit faces the five other fighters followed by a mirror-match finale. Each match is first to two rounds. Early opponents hesitate more; later opponents use the full existing bot policy. Health, damage and online rules are unchanged. Wins save the next opponent; losses can retry the current fight. Circuit progress is browser-local under `terminl:rumble-circuit:v1`.
- **Moon Mission:** `/os/moon` has a connected ten-level campaign. Routes are 13,000–26,000 world units, compared with the former 4,000–6,400. Levels allow five to eight minutes each. An uninterrupted automated traversal takes over thirteen minutes; exploration and retries add time.

## Moon progression

| Level | World | Main challenge |
|---|---|---|
| 1 | Degen District | Broad landings, double-jump fundamentals |
| 2 | Neon Rooftops | Stepped rooftops and high routes |
| 3 | Emerald Overgrowth | Hopping sentries |
| 4 | Diamond Caverns | Tall crystal stairways |
| 5 | Sunset Dunes | Wider gaps and collapsing bridges |
| 6 | Cold Storage | Slippery acceleration and braking |
| 7 | Liquidation Foundry | Warning lights before vent bursts |
| 8 | Cloud Nine | Moving sky platforms |
| 9 | Orbital Shipyard | Security vents and denser sentries |
| 10 | Tranquility Base | Mixed gauntlet and the Liquidation Warden |

The final arena locks while the Warden lives. It telegraphs a charge, releases ground shockwaves, then exposes blue armor. Stomp its head during that opening. Six hits defeat it; attacks get faster as health falls. The rocket cannot complete the campaign before the boss is defeated.

New levels unlock sequentially. Cleared levels can be replayed. Checkpoints save the current level and safe spawn, including the boss entrance. Retrying restores three health; previously passed pickups are removed and the attempt's score starts fresh. Saves use `terminl:moon-campaign:v1`; the old OS profile is left intact. Storage failure is reported and play continues for the current visit.

Keyboard, touch and controller input are supported. Blur, hidden tabs and pause release input. Portrait and landscape layouts keep controls outside the playfield.

## Verification

- `npm run test:os`: legacy replay coverage and the new campaign's traversal, boss, save, unlock, mechanic and render checks.
- `npm run test:arcade`: racing, combat, input, network and six-fight circuit checks.
- `npm run test:arcade:v1`: browser checks for flagship order, removed clutter, mobile controls, pause, circuit resume and all ten campaign wins through ordinary keyboard inputs. An accelerated animation clock samples rendering while leaving simulation state and save data untouched.
- `npm run test:rumble:circuit:browser`: wins all six circuit fights through keyboard input and verifies saved advancement and the mirror finale.
- `node scripts/arcade-visibility.mjs`: default production launcher and fighting-game navigation; asset tools stay gated.
